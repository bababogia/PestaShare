PestaShare is a hyper-local "smart bulletin board" designed to reduce waste in student dormitories by keeping resources circulating within the community. Built with native Kotlin, Jetpack Compose, and Firebase, the app allows departing students to quickly list usable household goods, while new arrivals can claim them using a non-monetary Eco-Point system. By keeping coordination inside the app and restricting access to verified residents, PestaShare provides a frictionless, trusted environment that replaces the linear "buy-use-discard" cycle with a sustainable sharing network.
